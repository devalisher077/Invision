# InvVision Jective team (KZ,Uralsk)

## Основные реализованные функции

1. **Подача онлайн-заявки** — абитуриенты могут заполнить и отправить заявку через веб-интерфейс (Похожий к дизайну Invision U офиц. сайта ).
2. **Пошаговая форма** — процесс подачи заявки разбит на этапы: личные данные, образование, внутренний тест и др.
3. **Загрузка документов** — поддерживается загрузка сертификатов, аттестатов, видео-презентаций, достижений и эссе.
4. **AI Scoring для приёмной комиссии** — отдельный раздел для комиссии, где по email кандидата можно получить всю информацию о нём, включая:
	- Личные данные
	- Результаты тестов
	- Ссылки на видео и документы
	- Ответы на вопросы
5. **Удобная навигация** — вкладки для быстрого перехода между разделами анкеты.
6. **Интеграция с Supabase** — хранение и получение данных о пользователях, документах и результатах тестирования.

Все загруженные материалы и информации о кандидате хранится в облачной инфраструктуре для дальйней удобной реализации AI scoringа

Для запуска проекта нужно установить npm install (node module)
Во время нажатия кнопки Ai scroing для приемной комиссии можете ввести почту кандидата jective@gmail.com или test77@gmail.com которые сейчас в базе имеются с полными дата сетом для проверки информации о кандидате. Также можете заполнить все поля для этого нужно зарегестрироваться и далее проверить этого же пользователя от вида приемной комиссии.
